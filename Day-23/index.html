Database Groundwork

Follow these steps to establish your local MongoDB environment, verify connection, and create your first visual database using MongoDB Compass.

1. Install MongoDB Server

  1. Download MongoDB Community Server from official site for your OS (Windows/macOS/Linux).
  2. Run the installer with default settings. On Windows, include MongoDB as a service.
  3. On macOS/Linux, use Homebrew or package manager: brew tap mongodb/brew && brew install mongodb-community.

2. Verify Connection

  1. Open terminal/command prompt.
  2. Start MongoDB: mongod (or sudo brew services start mongodb/brew/mongodb-community on macOS).
  3. In new terminal, connect: mongosh or mongo. You should see "test> " prompt.
  4. Run db.version() to confirm. Exit with exit.

3. Install & Use MongoDB Compass

  1. Download MongoDB Compass from official site.
  2. Install and launch. Connect to mongodb://localhost:27017.
  3. Click + next to "Databases". Enter DB name (e.g., "myFirstDB") and Collection name (e.g., "users").
  4. Click "Create Database". Add data via "Add Data" > "Insert Document".

Your first visual database is now ready! View schema, documents, and indexes graphically.
